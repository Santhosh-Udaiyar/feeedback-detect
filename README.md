# Online Feedback Collection System

## 📌 Project Description

This project is a database-driven application designed to collect and manage user feedback efficiently. It replaces traditional methods and provides a digital platform for feedback submission and analysis.

## 🚀 Features

* User feedback submission with rating
* Admin dashboard for analysis
* Feedback status tracking
* Secure login system

## 🛠️ Technologies Used

* MySQL
* DBMS Concepts
* HTML, CSS (Frontend)
