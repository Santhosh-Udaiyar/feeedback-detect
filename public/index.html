Features

Everything you need to manage feedback

Powerful tools built for real-world feedback management workflows.

🔐
Secure Authentication
JWT-based authentication with bcrypt password hashing. Rate-limited login to prevent brute force attacks.
⭐
Star Rating System
Intuitive 1–5 star ratings with category classification. Beautiful interactive star selector.
📊
Admin Analytics
Real-time dashboard with average ratings, monthly trends, category breakdowns, and status tracking.
🛡️
SQL Injection Safe
All queries use parameterized statements. Helmet + CORS protection. Input validation on every endpoint.
⚡
RESTful API
Clean, modular Express REST API with proper HTTP status codes, error handling, and pagination.
📱
Fully Responsive
Mobile-first design that looks stunning on all screen sizes. Dark glassmorphism aesthetic throughout.
